# Registro de cambios

Este historial recoge las funcionalidades incorporadas durante el desarrollo conversacional del editor. **No representa una versión semántica ni una auditoría integral.**

## 2026-11-05 — Publicación inicial en GitHub

- Publicación del editor autónomo `editor-md.html`.
- Documentación del proyecto, guías de uso, arquitectura y criterios de prueba.
- Registro explícito de los límites de Pluma Mesh, almacenamiento local y asistente Ollama.

## Mejoras integradas antes de la publicación

- Conservación localizada de Markdown para reducir cambios de formato en Git.
- Panel de búsqueda y reemplazo con soporte de expresiones regulares.
- Pestañas de documentos y borradores individuales.
- Resaltado básico de JS, Python, HTML, CSS, JSON y Bash.
- Front matter YAML, alertas GitHub y representación de Mermaid como código.
- Plantillas: En blanco, Registro de Show & Tell, Acta de reunión y README.
- DOCX con numeración en pie y estilos básicos para código.
- Historial con versiones, comparación y restauración.
- Pluma Mesh experimental con WebRTC, señalización manual y CRDT de caracteres.
- Integración opcional con Ollama local.

## Editor base

- Cinta de herramientas estilo Word; hoja centrada.
- Modos Visual, Markdown y Dividido.
- Listas, tareas, tablas, enlaces, imágenes, citas y bloques de código.
- Abrir, guardar y exportar Markdown, Word, HTML y PDF.
- Temas claro/oscuro/automático, esquema, zoom y arrastrar/soltar.
